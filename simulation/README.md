# 주식 수익률이 더 높은데, 채권을 왜 섞을까?

주식과 채권을 섞어 투자해야 한다는 개념은 알고 있었다. 두 자산이 서로 반대로 움직이면 하락 위험을 줄일 수 있기 때문이다. 하지만 장기적으로는 주식형 지수 상품의 수익률이 더 높았다. 그렇다면 주식 비중을 줄이면서까지 채권을 넣는 이유는 무엇인지 궁금해졌다.

부서 영업이사님이 자산배분 비중을 제안할 때 활용할 근거를 찾는 것도 목표였다. 단순히 “주식과 채권을 섞으면 좋다”고 말하는 대신, 과거 데이터를 바탕으로 비중별 차이를 보여주고 싶었다.

## 이 프로젝트에서 시도한 것

### 1. 채권 데이터를 투자수익률로 바꾸기

확보한 채권 데이터는 가격이나 분배금이 아니라 10년물 국채 만기수익률이었다. 이를 주가지수와 비교하려면 채권의 총수익 지수가 필요했기 때문에, 매일 금리 변화에 따라 가상의 10년물 채권 가격을 다시 계산하고 이자를 더하는 방식으로 수익률을 재구성했다.

### 2. 비중별 포트폴리오 비교

주식 비중을 0·20·40·60·80·100%로 나누고, 연 1회 리밸런싱하는 포트폴리오를 만들었다. 각 조합의 누적수익률, 연복리 수익률, 변동성, 최대낙폭을 비교했다.

### 3. 하락장에서 채권의 역할 확인

주식이 고점 대비 10% 이상 하락한 구간을 찾아, 같은 기간에 채권을 섞은 포트폴리오가 얼마나 덜 떨어지고 빨리 회복했는지 비교했다. 주식과 채권의 상관관계도 전체 기간, 주식 급락일, 연도별로 나눠 살펴봤다.

### 4. 위험 대비 수익 비교

분석 과정에서 샤프비율을 알게 되면서 비교 기준을 바꿨다. 수익률이 높은지만 보는 대신, 변동성에 비해 얼마나 효율적으로 수익을 냈는지 비교했다. 변동성이 낮은 혼합 포트폴리오의 투자 규모를 키워 주식 단독과 같은 변동성 수준에 맞추는 계산도 시도했다.

## 무엇을 알게 되었나

미국 데이터에서 주식 100%와 주식 40%·채권 60%를 비교하면 다음과 같았다.

| 지표 | 주식 100% | 주식 40%·채권 60% |
|---|---:|---:|
| 연복리 수익률 | 8.55% | 6.27% |
| 연환산 변동성 | 19.08% | 7.41% |
| CAGR ÷ 변동성 | 0.448 | 0.847 |

주식만 담았을 때 수익률은 더 높았다. 그러나 채권을 섞으면 변동성이 더 큰 폭으로 줄어 위험 대비 수익은 오히려 높아졌다. 이 결과를 통해 채권은 수익률이 낮은 자산이라서 의미가 없는 것이 아니라, 포트폴리오의 흔들림과 손실 규모를 줄이는 역할을 할 수 있다는 점을 이해하게 됐다.

또한 주식과 채권이 항상 반대로 움직이는 것은 아니었다. 미국의 전체 기간 상관계수는 약 -0.280이었지만 한국은 약 -0.039였고, 한국의 위기일 상관관계는 통계적으로 뚜렷하지 않았다. 시장과 기간에 따라 채권의 방어 효과가 달라질 수 있다는 점도 확인했다.

이 프로젝트를 시작할 때는 “주식보다 수익률이 낮은 채권을 왜 섞어야 하는가?”가 질문이었다. 분석을 마친 뒤에는 “같은 위험을 감수할 때 어떤 조합이 더 효율적인가?”로 질문이 바뀌었다.

## 다시 찾아볼 때

- `src/bond_tr.py`: 국채 만기수익률로 채권 총수익 지수 재구성
- `src/portfolio.py`: 주식·채권 비중과 리밸런싱별 포트폴리오 계산
- `src/exit_loss_simulation.py`: 하락구간 손실과 회복기간 비교
- `src/correlation_analysis.py`: 전체·위기일·연도별 상관관계 분석
- `src/run_all.py`: Python 분석 전체 실행
- `output/summary_report.md`: 분석 결과 요약
- `simulator/insight-note.html`: 분석 배경과 결과를 읽는 설명문
- `simulator/index.html`: 비중을 바꿔가며 결과를 확인하는 브라우저 시뮬레이터

## 실행

```bash
python3 -m http.server 8080 --directory simulation/simulator
```

브라우저에서 `http://localhost:8080`을 열면 시뮬레이터를 볼 수 있다. Python 분석을 다시 실행하려면 저장소 루트에서 `python3 simulation/src/run_all.py`를 실행한다.

채권 수익률은 만기수익률에서 재구성한 근사치이고, 배당·세금·거래비용은 반영하지 않았다. 따라서 결과는 특정 비중의 미래 성과가 아니라, 이 데이터와 조건에서 비중별 차이를 비교한 기록으로 해석한다.
