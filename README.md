# Bond Simulator

주식과 채권을 함께 담는 이유를 과거 데이터로 확인한 프로젝트다. 주식과 채권을 섞어야 한다는 말은 흔히 들었지만, 주식 비중을 줄였을 때 어떤 이점이 생기는지는 분명히 설명하기 어려웠다. 주식·채권 비중별 수익률과 위험을 비교해 자산배분의 근거를 찾고자 했다.

## 분석 내용

- 국채 만기수익률을 이용한 채권 총수익 지수 재구성
- 주식·채권 비중별 포트폴리오 계산
- 연 1회 리밸런싱 기준의 주식·채권 비중별 포트폴리오 계산
- 하락구간의 낙폭·회복기간 분석
- 전체 기간·위기일·연도별 상관관계 분석
- CAGR과 변동성을 이용한 위험 대비 수익 비교
- 결과를 확인할 수 있는 브라우저 시뮬레이터 구현

## 주요 결과

미국 데이터에서 주식 100%와 주식 40%·채권 60%를 비교했다.

| 지표 | 주식 100% | 주식 40%·채권 60% |
|---|---:|---:|
| 연복리 수익률 | 8.55% | 6.27% |
| 연환산 변동성 | 19.08% | 7.41% |
| CAGR ÷ 변동성 | 0.448 | 0.847 |

주식 비중을 낮추면 수익률은 줄지만 변동성과 하락 위험도 함께 줄었다. 수익률만 비교할 때와 위험 대비 수익으로 비교할 때 결과가 달라진다는 점을 확인했다.

## 폴더 구조

| 경로 | 설명 |
|---|---|
| `src/` | 분석 코드 |
| `data/` | 입력 데이터 |
| `output/` | 분석 결과 |
| `simulator/` | 브라우저 시뮬레이터 |
| `web/` | Best Days 제거 시뮬레이터 |
| `docs/research-process.md` | PAAR 경험 기록 |

## 실행

브라우저 시뮬레이터:

```bash
python3 -m http.server 8080 --directory simulator
```

Python 분석:

```bash
python3 src/run_all.py
```

채권 수익률은 만기수익률에서 재구성한 근사치이며, 배당·세금·거래비용은 반영하지 않았다.
