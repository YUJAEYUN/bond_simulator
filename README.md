# Bond Simulator

- 자산배분 시뮬레이터: https://bond-simulator-lac.vercel.app/
- Best Days 제거 시뮬레이터: https://chipper-meringue-d3e144.netlify.app/

Bond Simulator는 주식과 채권의 장기 투자 성과와 위험을 비교하는 백테스팅 프로젝트다. KOSPI·S&P500과 한국·미국 10년물 국채 데이터를 바탕으로 자산별 수익률, 하락폭, 회복기간, 상관관계, 비중별 위험 대비 수익을 분석하고 브라우저 시뮬레이터로 시각화했다.

금융세미나에서 장기투자 전략을 설명하기 위한 백테스팅 의뢰로 시작했다. 처음에는 “주식과 채권 중 무엇을 장기투자해야 하는가”를 확인하기 위해 KOSPI와 S&P500의 장기 데이터를 분석했고, 이후 주식 장기투자의 회복력과 채권의 위험 완화 역할을 비교하는 방향으로 확장했다.

수십 년의 지수 데이터를 보면 큰 위기 뒤에도 시장은 회복하고 새로운 고점을 만들어왔다. 반면 가까운 시점에 사용할 자금은 하락장에서 회복을 기다리기 어렵다. 그래서 자금의 사용 목적과 시점에 따라 투자 대상을 나누는 것이 합리적이라는 결론으로 이어졌다.

## 분석 내용

- 주식 수익률 상위일(Best Days) 제거에 따른 장기 수익률 변화 분석
- 국채 만기수익률을 이용한 채권 총수익 지수 재구성
- 연 1회 리밸런싱 기준의 주식·채권 비중별 포트폴리오 계산
- 하락구간의 낙폭·회복기간 분석
- 전체 기간·위기일·연도별 상관관계 분석
- CAGR과 변동성을 이용한 위험 대비 수익 비교
- 결과를 확인할 수 있는 브라우저 시뮬레이터 구현

초기 분석에서는 KOSPI와 S&P500의 수익률이 가장 높았던 날을 제외해 장기 수익률 변화를 확인했다. 큰 상승일은 큰 하락 이후 짧은 기간 안에 나타나는 경우가 많았고, 하락장에서 패닉셀하면 회복과 반등을 놓쳐 장기 수익률이 크게 낮아질 수 있다는 점을 확인했다.

## 주요 결과

미국 데이터에서 주식 100%와 주식 40%·채권 60%를 비교했다.

| 지표 | 주식 100% | 주식 40%·채권 60% |
|---|---:|---:|
| 연복리 수익률 | 8.55% | 6.27% |
| 연환산 변동성 | 19.08% | 7.41% |
| CAGR ÷ 변동성 | 0.448 | 0.847 |

주식 비중을 낮추면 수익률은 줄지만 변동성과 하락 위험도 함께 줄었다. 장기간 사용할 자금과 가까운 시점에 사용할 자금을 구분하고, 각 목적에 맞는 자산을 선택해야 한다는 판단으로 이어졌다.

## 폴더 구조

| 경로 | 설명 |
|---|---|
| `src/` | 분석 코드 |
| `data/` | 입력 데이터 |
| `output/` | 분석 결과 |
| `asset-allocation/` | 주식·채권 자산배분 시뮬레이터 |
| `best-days/` | Best Days 제거 시뮬레이터 |
| `docs/research-process.md` | PAAR 경험 기록 |

## 실행

브라우저 시뮬레이터:

```bash
python3 -m http.server 8080 --directory asset-allocation
```

Python 분석:

```bash
python3 src/run_all.py
```

채권 수익률은 만기수익률에서 재구성한 근사치이며, 배당·세금·거래비용은 반영하지 않았다.
